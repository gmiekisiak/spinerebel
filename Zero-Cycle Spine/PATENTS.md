## Application numbers

Deliberately not listed. The article declares the filings as pending without
enumerating them, and this repository follows the same convention so that the
public record is consistent. Enumerating application numbers here would make
the portfolio trivially mappable while adding nothing the article does not
already disclose.

Apply the same answer to the AO Foundation application, so that all three
disclosures agree.

Note that not every SpineRebel filing relates to this work. The
spinal-exposure-dosimeter application (vectorial spinal dosimetry) is a
separate invention and should not be cited as though it covered the Zero-Cycle

## A note on choice of code licence

Do **not** license this code under Apache-2.0. Apache-2.0 §3 grants every
recipient an express, royalty-free patent licence covering the contributor's
claims necessarily infringed by the contribution. That directly undermines a
licensing strategy built on the patent portfolio.

MIT and BSD-3-Clause contain no express patent grant, which is why MIT plus
this notice is used here. Implied-licence and exhaustion arguments can still be
raised against any public release, so the final choice should be confirmed with
patent counsel.
